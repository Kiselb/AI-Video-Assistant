# Смысл — AI-анализатор видеовстреч

Локальное одностраничное приложение принимает запись встречи в WebM или MP4 с
компьютера либо по публичной ссылке Google Drive, извлекает аудио через FFmpeg,
распознаёт речь через OpenAI API и формирует конспект: краткое содержание,
решения, задачи и открытые вопросы.

Результаты хранятся **только в `localStorage` браузера**. Сервер использует
временные файлы только на время фоновой задачи и удаляет их после обработки.

## Требования

- Python 3.11+
- FFmpeg, доступный как команда `ffmpeg`
- доступ к OpenAI-совместимому прокси

## Настройка

1. Создайте виртуальное окружение и установите зависимости:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   python -m pip install -r requirements.txt
   ```

2. Скопируйте `.env.example` в `.env` и заполните обязательные значения:

   ```dotenv
   PROXY_API_API_KEY=ваш_ключ
   PROXY_API_OPENAI_BASE_URL=https://адрес-прокси/v1
   ```

   При необходимости измените `OPENAI_TRANSCRIPTION_MODEL` и
   `OPENAI_SUMMARY_MODEL` на имена моделей, доступных в вашем прокси.

3. Запустите приложение:

   ```powershell
   python -m uvicorn app.main:app --reload
   ```

4. Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000).

## Импорт из Google Drive

1. Загрузите WebM или MP4 в Google Drive.
2. В настройках доступа выберите «Все, у кого есть ссылка» с правом просмотра.
3. Скопируйте ссылку вида
   `https://drive.google.com/file/d/ИДЕНТИФИКАТОР/view` и вставьте её в поле
   «Ссылка на видеозапись Google Drive».

Приложение не авторизуется в Google и не обходит ограничения доступа. Если
файл закрыт, будет предложено скачать его самостоятельно и использовать ручную
загрузку. Повторная вставка ссылки на уже готовую запись открывает сохранённый
результат вместо нового анализа.

Обе точки входа создают одну и ту же фоновую задачу со статусами «Получение
файла», «Распознавание речи», «AI-анализ», «Готово» и «Ошибка». Во время работы
обрабатывается только одна запись.

## Проверка

```powershell
python -m pip install -r requirements-dev.txt
python -m pytest
```

## Как устроено хранение

Название файла, источник, нормализованная облачная ссылка, дата, статус,
расшифровка и конспект сохраняются в ключе `meeting-analyzer:meetings:v1` в
`localStorage`. Исходное видео и аудио не сохраняются. После обновления страницы
интерфейс продолжает опрашивать активную задачу, пока сервер не перезапущен.
